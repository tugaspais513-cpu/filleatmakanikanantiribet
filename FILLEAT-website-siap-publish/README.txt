# FILLEAT Website

Website landing page + katalog sederhana untuk FILLEAT berdasarkan proposal Fisheries Digital Marketing.

## Isi
- `index.html` — halaman utama
- `style.css` — desain responsif
- `README.txt` — panduan publish

## Sebelum publish
1. Buka `index.html`.
2. Cari `6281234567890`.
3. Ganti dengan nomor WhatsApp bisnis FILLEAT dalam format internasional tanpa tanda `+`.
4. Jika sudah punya foto produk, foto dapat ditambahkan nanti pada kartu produk/hero.

## Publish gratis dengan Vercel
1. Buat akun GitHub.
2. Buat repository baru, misalnya `filleat-website`.
3. Upload `index.html` dan `style.css`.
4. Buka Vercel dan login dengan GitHub.
5. Import repository `filleat-website`.
6. Klik Deploy.
7. Website akan mendapatkan alamat gratis berakhiran `.vercel.app`.

Website ini tidak membutuhkan database atau server, sehingga cocok untuk demo/tugas dan landing page sederhana.
